# Initial 36-case review snapshot

This release contains the 36 case packages from the initial validated pool:
the six expert-review cases, ten cases from `master`, and twenty cases from
`master-v4`. The complete packages are under `cases/`; each package includes
its public task, runtime, evaluator, and provenance artifacts as present in
the local validated release.

These packages are uploaded for expert review. The later compact-diverse
Docker-gated wave is kept in its own local staging and release records.
